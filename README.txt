Quran Hifz Companion — V10.1 FIXED

This build fixes the V10 lesson/revision speech workflow and packaging.

Lesson recitation:
- Start recitation → Stop & score.
- Final transcript is scored only after an explicit Stop & score action.
- Interim speech is shown as a live comparison but is not saved as a Hifz result.
- Accuracy, missing words, and extra words are shown.
- Save verified result records the new-learning result and adapts the schedule according to the existing 75% / 90% rules.
- A direct “Save verified result” button appears after a scored recitation.

Revision:
- Last 6 completed new-learning lessons are shown automatically.
- Each selected lesson can be read, listened to, and recited.
- Stop & score records revision accuracy for self-monitoring only.
- Revision scores do NOT move the Hifz cursor or change the new-learning schedule.
- Unexpected speech-recognition disconnects do not silently create a revision score.

Other fixes:
- Footer correctly identifies Final build 10.1.
- Internet Archive opening-page viewer uses the supported embedded BookReader URL.
- PWA manifest and icons are included in the ZIP package.

Speech recognition remains an approximate practice aid, not Tajweed/makharij certification, and browser support is limited.
